# $Happy Meme Vault

## Put it on GitHub Pages
1. Create a new repository on GitHub and upload everything in this folder (keep the structure).
2. Go to Settings > Pages > Deploy from a branch > main > / (root) > Save.
3. Your site goes live at `https://YOUR-USERNAME.github.io/REPO-NAME/` in about a minute.

## Add videos and pictures
1. Put video files (.mp4 works best) in `assets/videos/` and pictures in `assets/pictures/`.
2. Open `js/media.js` and add a line for each one, for example `{ file: "clip1.mp4", title: "My clip" }`.
3. Commit and push. The new items appear on the site.

GitHub blocks single files over 100 MB, so compress large videos first.
